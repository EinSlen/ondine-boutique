# Génération intégrée — extension de collection

09.09.2026. Mode intégré imagegen, pas de CLI ni d’API facturée séparément. Les prompts exacts et les chemins des sorties sont conservés dans `generation.json`. Les sources demandées en grand format peuvent être retournées plus petites par l’outil ; seules les dimensions réellement mesurées font foi.

Rôles : les références catalogue guident la coupe et la construction uniquement. Leurs modèles, motifs et textes ne sont pas repris. Les images de vêtements finales sont des simulations générées, pas des photos de produits fabriqués.

Contrôle initial : illustration de clé lisible ; motif rayé adéquat comme étude de surface mais raccords et échelle d’impression non validés ; lettrage NOT NOW initial rejeté à cause d’artefacts blancs dans les espaces transparents. Une correction ciblée est requise avant mockup de broderie.
