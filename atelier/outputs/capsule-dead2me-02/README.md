# dead2me — capsule visuelle 02

Trois compositions originales utilisant des silhouettes CC0 de la bibliothèque locale :

- `01-dont-wait-for-me.png` — fuite, porte qui se désagrège, trace bordeaux.
- `02-you-left-the-room-first.png` — personnage isolé, téléphone décroché, séparation verticale.
- `03-we-never-said-goodbye.png` — départ hors cadre, chaise laissée vide.
- `apercu-capsule-02.png` — planche de contrôle sur fond écru.

Les trois dessins sont des PNG RGBA à fond réellement transparent. Ce sont des prototypes de
direction artistique ; le concept retenu devra être refait ou agrandi en master d'impression
selon le gabarit exact du produit.

## Sources CC0

- Running woman : https://openclipart.org/detail/263156
- Seated distressed man : https://openclipart.org/detail/320824
- Walking woman : https://openclipart.org/detail/220954

La bibliothèque locale documente ces fichiers sous CC0 1.0, avec usage commercial et
merchandising autorisés. Les compositions, textes, placements et interventions bordeaux de
cette capsule sont nouveaux ; aucun pull Live2die n'a été reproduit.

## Prompts de production

Mode utilisé : outil ImageGen intégré, puis passe `background-extraction` pour obtenir un vrai
canal alpha.

- `DON'T WAIT FOR ME` : silhouette de coureuse CC0, ligne d'horizon bordeaux interrompue,
  petite porte qui se désagrège, sérigraphie sèche noire et bordeaux.
- `YOU LEFT THE ROOM FIRST` : silhouette assise CC0 seule dans un grand cadre, petit téléphone
  décroché, séparation verticale bordeaux, texte vertical.
- `WE NEVER SAID GOODBYE` : silhouette marchant hors d'un cadre ouvert, chaise bordeaux vide,
  horodatage `04:17`, composition horizontale.

Contraintes communes : fond transparent, deux encres maximum, texture photocopie/sérigraphie,
aucun logo tiers, aucune arme, aucun gore et aucune reprise d'une composition existante.
