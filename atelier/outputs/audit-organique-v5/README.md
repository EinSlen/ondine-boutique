# Audit organique — version neutre 5

Recherche datée du 6 septembre 2026. Ouvrir `index.html` dans un navigateur ; conserver le dossier `assets` à côté. Aucun serveur requis. Le document n’est pas une boutique ou un thème Shopify prêt à publier.

## Décisions et état réel

- « Sour Hours » et « Mauvais Pli » ont été rejetés par Valentin. Aucun nouveau nom n’est retenu ou appliqué.
- Six marques examinées : Scuffers, Nude Project, Cold Culture, derschutze, Arte Antwerp, PESO. Échantillon qualitatif, pas classement des meilleures ventes EU ni preuve de ventes organiques par référence.
- Six essais de nom sont créatifs, sans recherche juridique d’antériorités aboutie ni disponibilité de domaine/identifiant vérifiée. Une recherche web préliminaire n’établit aucun droit.
- Trois images locales sont d’anciennes simulations IA V4, portant encore l’ancien marquage. Elles servent uniquement à la revue critique. Elles ne constituent pas des photos de produits fabriqués ou trois nouveaux designs.
- Les huit vêtements/accessoires V4 sont réévalués : deux axes de produits à redessiner avant un éventuel échantillon, une réserve de test, cinq développements différés. Aucun produit n’est approuvé pour la vente.
- Prix produits : cibles non validées. Prix fournisseurs : montants publics et technologies spécifiques, pas devis pour notre collection.
- Douze scripts conditionnels sont préparés. Aucun contenu publié, aucune vente mesurée, aucun fournisseur contacté, aucune commande ou réservation effectuée.
- L’ancienne boutique n’est pas écrasée. La branche de travail portant le nom rejeté n’est pas livrée comme nouvelle marque.

## Utilisation du journal

Les préférences de nom et observations sont enregistrées manuellement dans le stockage local du navigateur sous la clé `ondine-neutral-audit-v5`. Aucune transmission réseau, compte connecté, mesure automatique ou donnée client collectée. Une case vide signifie inconnu ; zéro signifie mesuré à zéro. Les pourcentages sont descriptifs et supposent des périmètres comparables, pas une preuve causale d’attribution.

Exporter le JSON pour conserver les notes. Déplacer le dossier, changer de navigateur ou nettoyer le stockage peut isoler/effacer les données locales. Aucun import JSON n’est implémenté. Le bouton « Retirer » demande confirmation ; un export antérieur reste intact.

## Sources et limites

Sources directes associées à chaque constat dans le HTML. Les déclarations de marques et agences ne sont pas des données auditées indépendantes. Le trafic direct n’est pas assimilé à l’organique. Les programmes de récompense, affiliation et publicité sont distingués.

Les étapes juridiques France/UE sont une checklist de vérification au jour de la recherche, pas un audit de conformité complet. Le document n’implémente ni checkout, ni rétractation en ligne, ni politique légale de boutique.
