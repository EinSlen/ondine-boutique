D2M / DEAD2ME — SUPPLIER READY PACK
=====================================

PREFERRED LAUNCH SUPPLIER: PRINTFUL

WHY:
- One supplier keeps sizing, mockups, fulfillment and customer support simpler for the first drop.
- Gildan 18600 supports front/back + sleeve placements and has overlapped fabric across the zipper.
- Cotton Heritage MC1087 supports front/back and left/right sleeve DTG.
- The three bottoms use Printful all-over cut-and-sew products so the burgundy details can continue around the garment.

IMPORTANT — EXACT REALISM
The files in 01_GRAPHIC_PIECES are the extracted artwork from the original garment references.
The sleeve files are separate on purpose: a front print alone cannot reproduce the burgundy splatter on the sleeves.
For every hoodie, add BOTH sleeve placements in the supplier editor.

PLACEMENT STARTING POINTS
- Large tee print: 28–32 cm wide
- Small chest logo: 8–10 cm wide
- Large back D2M: 28–34 cm wide
- Zip graphic: use the provider front-print canvas, centered on the zipper; do not merge the left/right composition incorrectly.
- Sleeve splatter: use Long Left Sleeve / Long Right Sleeve when available; keep most droplets below the shoulder.
- Bottoms: the 6000px AOP files are design canvases. They still need to be placed inside the supplier's official cut-panel template.

WHAT IS STILL PROVIDER-SPECIFIC
Printful generates a different production template for each product/panel. Those cut lines cannot be created reliably from Shopify alone.
Open the product in Printful, choose the blank above, then upload the matching file and use the exact provider template.
Do not publish fulfillment until every Shopify size is marked SYNCED in Printful.
